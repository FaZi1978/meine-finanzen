# Meine Finanzen

Persönliche Web-App zum Erfassen von Einnahmen, Ausgaben und Kontoständen.

- Läuft komplett im Browser, ohne Server und ohne Anmeldung bei einem Dienst.
- Alle Daten bleiben auf dem jeweiligen Gerät und werden mit einem selbst gewählten Passwort verschlüsselt (AES-256).
- Dieses Repository enthält nur das Programm, keine Finanzdaten.

**App öffnen:** über GitHub Pages dieses Repositorys.

Daten zwischen Geräten übertragen: in der App „Backup speichern“ und auf dem anderen Gerät „Backup laden“.
